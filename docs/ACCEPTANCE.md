# 验收标准

## 层级

- 安装/冒烟：9×9 三轨到0.04 s；只要求推进、终态有限、密度正、checkpoint/final/末快照密度完全一致。它不代表60 s或成熟EPB科学验收。
- 数值验证：`python -m esf_sim validate-em` 九阶段；以及迁移回归测试。合成小网格的通过不代替生产案例。
- 科学案例：运行器调用该案例冻结源码的 `em_growth_acceptance.write_acceptance_report`。必须读取 `pass`、`failures`、`warnings`；终态输出存在或程序推进完成不足以判定通过。

## reduced-EM 门槛

完整、可执行策略位于对应源码 `esf_sim/em_growth_acceptance.py` 的 `THRESHOLDS`，每份验收JSON也归档 `policy`。以下摘录不替代完整规则：

| 指标 | 硬失败门槛 |
|---|---|
| 密度 CFL | >0.2500001 |
| 耦合 CFL | >0.4000001 |
| 相对耦合残差 | >1e-8 |
| 端口功率配对缺陷 | >1e-8 |
| 净表面FAC比率 | >1e-10 |
| 周期端点相对不匹配（适用旧布局时） | >1e-6 |
| 线能量非物理创造占交换量 | >5e-3 |

还需配置哈希、三轨结构、有限正密度、增长窗、FAC/重力、时间步和耗空泡形态等检查。成熟阶段包括耗空阈值0.25、泡顶至少430 km、跨度至少80 km、面积至少500 km²、最大耗空至少0.50、至少10层有两格宽结构；具体增长条件由代码执行。60/300/3150 s政策不同，不能用60 s通过代替成熟增长。

`load0p2/load5` 使用独立 `equivalent_passive_conductance_t60_v1` 策略；其原 matched 策略失败报告也保留，不能隐去或混为同一判据。该独立策略只用于等效被动负载60 s敏感性。

## 静电作者数据对照

`metrics.compare_with_reference` 的原门槛：泡顶绝对误差≤25 km、耗空面积相对误差≤25%、密度1%与99%分位各≤10%。Figure 2还检查数值格式形态/精细结构层级；Figure 3检查低alpha组相对高alpha组的趋势，严格逐alpha单调性仅作诊断。完整报告需要作者MAT文件。

## 历史比较

`benchmarks/` 存放小体积历史科学验收报告，保留原有失败和警告。新机必须独立产出报告和图件；历史 `pass=true` 不会自动成为新机通过。A/B受控对照的重要历史观测：共同300–3150 s拟合 EM gamma A≈4.1575784869e-4、B≈4.0958246371e-4 s^-1，B相对A−1.4853%；两ES控制在旧实验逐字节一致。该拟合来自同0.25 s插值logRMS分析，不要直接与采用其他窗/采样权重的runner斜率比较。两EM无清晰Y。见 `docs/history/EPB_CONTROL_B_T3150_REVIEW_2026-10-10.md`。
