# 跨电脑交接（2026-11-09）

本仓库将后期 reduced-EM 工作树的实际源码（包括原先未提交的文件）、静电复现代码、小配置、测试和历史验收证据整理为独立轻量版本。它不是原项目全部数据的备份，也不包含原 Codex 聊天全文。

## 接手顺序

1. 阅读 README，重建虚拟环境；不要沿用旧电脑的绝对路径。
2. 查看 `docs/VALIDATION.md`，区分本次实际执行的验证和历史记录。
3. `python scripts/reproduce.py list`，先执行 `run smoke`。
4. `check B --stage 60`，核对源码与配置，然后明确执行 `run B --stage 60`。
5. 检查新的 `terminal_audit.json`、`reproduction_acceptance.json`、`reproduction_provenance.json` 和 `postprocess/` 图件。没有失败才考虑成熟期案例；长计算需明确选择。

## 版本与物理解释

原 E 盘 checkout 和 reduced-EM 工作树不是同一代码版本。本仓库的 `src/` 来自后者；`provenance/source_inventory.json` 给出逐文件哈希，不能仅用原 Git 初始提交标识它。A/B 和敏感性案例优先加载 `source_history/` 的相应冻结源码；C/D 无可确认的独立冻结包，使用当前源码，不能声称字节级重现历史轨迹。

截至历史记录，A/B/C/D 均有 3150 s 结果；D 另有 5000 s 记录，已超过旧的“细网格仅到1050 s”交接状态。后续共同密度漂移10/20 m/s、半场线长度和等效被动负载研究有60 s阶段证据。各案例具体是否通过，以 `cases.json` 列出的原始验收报告为准。`docs/history/` 是按日期保留的历史材料，旧计划/进程/状态不得当作新电脑当前事实。

研究结论仍为：恢复 EM 主增长，但成熟 EM 泡通常宽而平滑，没有清晰 Y 分叉；不可称问题完全解决。三轨必须同时保留；EM−column ES 才分离电磁效应。禁止翻转 FAC、恢复固定电压短路或减弱反馈来制造增长。使用独立 H_n/H_nu，推进粒子列 N=H_n n。恒定 V_A、简化横向映射、无平行质量再分布/化学/中性风等限制仍存在。

## 迁移边界

没有上传旧 checkpoint，因此新电脑从解析初态重新算；无法直接恢复旧机中途计算。未包含 FARR/IRI 外部软件工作流、论文 PDF、作者 MAT 文件、完整输出和电影。若以后需要 FARR，应单独整理外部软件版本及输入来源，不与 reduced-EM 验收混用。

模型、配置哈希、源码哈希与线程数都应保留。跨平台/BLAS版本可能导致分支位置变化；按冻结验收指标、同物理时间的形态和增长拟合评估，不能临时编造跨电脑百分比容差。采样能量预算不等同精确 RK-stage 功；开放边界粒子列漂移不是封闭系统守恒误差。
